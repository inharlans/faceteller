FaceTeller CNN·깊이 혼합 점수 서비스 적용
적용일: 2026-10-14
정책 버전: cnn_depth_geomean_v1

적용 범위
사용자가 추가로 결정한 깊이 점수 방식을 실제 /api/v1/analysis 응답과 문헌 선정에 적용한다.
제출본 PDF의 5.5에서 '깊이는 조건 검사에만 사용'하던 부분을 아래 방식으로 변경한다.
원본 제출 PDF는 수정하지 않는다.

1. 특징별 점수
CNN 분류 항목: 기존 검증 자료로 보정한 분류 신뢰도.
깊이 항목: 두 경계와 반복 측정 σ를 사용한 해당 구간 점수.
A=Φ((r-b1)/σ), B=Φ((r-b2)/σ)
낮음=1-A, 보통=A-B, 높음=B.
낮음·보통·높음 레이블은 점수 최댓값이 아니라 경계와 측정값을 비교해서 결정한다.
현재 400명 경험적25%·75% 경계와 학습군26명 반복 측정 σ를 그대로 사용한다.
깊이 점수에 임의 가중치나 점수 상한 정규화를 추가하지 않는다.

2. 후보 인정
문헌 조항에 연결된 전체 필수 레이블이 모두 확정된 경우만 후보로 인정한다.
보류·미측정·모델 미학습 특징을 필요로 하는 조항은 제외한다.
동일 문헌 조항은 중복 집계하지 않는다.
CNN의 기존 신뢰도 기준값과 품질 검사는 유지한다.
깊이는 기존 촬영방향·측정 가능 여부 검사를 유지하고, 점수가 없거나 유효한0~1 수치가 아니면 보류한다.
깊이에 CNN의0.6 기준을 새로 적용하지 않는다. 아직 검증하지 않은 공통 보류 기준을 만들지 않기 위함이다.

3. 혼합 점수
G=(s1×s2×…×sn)^(1/n)
n은 해당 조항의 필수 조건 중 실제 반영한 CNN 항목과 깊이 항목의 총개수다.
각 특징의 가중치는 같다. CNN 전체와 깊이 전체를 각각50%로 만드는 방식은 아니다.
계산은 exp(sum(log(si))/n)으로 수행한다. 하나라도0점이면 G=0이다.
깊이 항목만 있는 조항도 동일한 식으로 점수를 계산하여 함께 경쟁한다.
이전처럼 깊이 조항을 항상 뒤로 보내지 않는다.
G는 문헌 후보의 종합 일치점수이며, 정답일 확률이 아니다.

4. 정렬과 제한
G 내림차순. 동점이면 기존 문헌 우선순위 → 조항 순서 → 조항 식별자 순.
해당 조항의 관련 부위에 각각1개씩 집계하며 같은 부위는 최대3개.
전체 최대5개. 후보가 부족하면 있는 후보만 반환한다.
특징 개수에 대한 추가 가산점이나 임의 문헌 생성은 없다.

5. API와 화면
항목의 confidence에는 CNN 신뢰도만 담는다. 깊이의 confidence는 null을 유지한다.
깊이 점수는 measurement_score로 별도 제공하며 문헌 G 계산에 사용한다.
문헌 응답에 rank, G, score_feature_count, score_components를 포함한다.
score_components에는 각 필수 항목의 종류·레이블·점수를 담는다.
응답 ranking_policy에 점수 방식과 정책 버전을 명시한다.
결과 화면은 서버의 순위를 유지하며 '종합 일치점수 xx.x점'과 항목별 계산 근거를 보여준다.
인쇄 결과에는 순위와 종합 점수를 표시한다.

기존 데이터와 모델을 사용한 로컬 서비스다. 이번 변경은 문헌 점수·선정·표시를 연결한 것이다.
새7개 부위 모델 미학습, 문헌 독립 검수 미완료, 깊이의 실제3D 정답 검증 미완료 상태는 유지된다.
실제 서비스 추론에서 얼굴 사진이나 분석 이력을 저장하지 않는다.
개발 검증 스크립트가 저장하는 수치 보고서는 별도 실험 산출물이다.
