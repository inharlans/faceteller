# 형태 레이블과 문헌 해석 연결 설계

작성일: 2026-09-22. 설계안이며 기존 v1 레이블·모델·서비스 판정을 변경하지 않는다.

## 1. 사진보다 먼저 구축할 수 있는 지식

문헌 유형 ID → 판본·출처 → 형태 조건 → 전통 해석 원문·번역 → 주제별 평가 → 서비스 설명문을 별도 사전으로 구축한다. 이 작업에는 얼굴 사진 레이블링이 필요하지 않다. 사진의 정답은 관찰되는 형태이고, 해석 사전은 문헌이 무엇을 주장하는지에 대한 기록이다. 개인의 실제 복·재산·성격을 확인한 정답 데이터가 아니다.

단일 good/bad 값 대신 재물·지위·관계·수명 등 주제별로 길/흉/혼합/언급없음/해석보류를 기록한다. 서로 다른 판본은 별도 레코드로 보존한다. 원문 근거가 없는 주제를 보충하지 않는다. 원문의 차별적·인격 비난 표현은 역사 자료 설명으로만 보존하며 사진 속 사람에게 적용하는 문장으로 출력하지 않는다.

귀미(鬼眉)의 해당 원문은 `眉粗壓眼`이라는 형태와 부정적인 인격·행동 주장을 함께 담고 있다. 이를 '복이 없다'로 바꾸면 원문에 없는 의미를 덧붙이게 된다. 녹비(鹿鼻)의 `福祿增添`, 우구(牛口)의 `富貴康寧`처럼 복록을 언급하는 사례는 해당 주제의 전통적 길상 해석으로 기록할 수 있다.

연결은 세 종류다: 전체 유형 조건 충족 / 일부 형태만 공통 / 판정 불가. 기존 literature_links.json의 8건은 모두 일부 형태 참고이며 전통 유형 확정이 아니다. 전체 조건을 정의·검수하기 전에는 부분 연결을 전체 유형과 해석으로 승격하지 않는다. 서비스는 '이 문헌은 이 유형을 이렇게 설명한다'는 출처 중심 문장으로 보여준다.

현재 문헌 103건의 원문·출처를 interpretation_catalog_v1.json으로 연결했다. 103건 모두 해석 요약·주제별 평가·근거 구절을 작성했다. 완역·판본 교감이나 전문가 검증 완료를 의미하지 않는다. 검토할 구절은 항목별로 표시했다.

## 2. 형태 레이블의 조작적 정의

| 사용자가 말하는 특성 | 채택할 레이블·측정 | 입력·제약 |
|---|---|---|
| 코가 크다 | 우선 '얼굴 대비 코 폭이 넓다'로 분리. 콧방울 외측 사이 거리 / 얼굴 좌우 외곽 기준 폭 | 정면 전체 얼굴. 코만 확대한 crop은 분모 소실 |
| 코가 길다 | 코뿌리~코밑 기준 길이 / 동일 정의의 얼굴 기준 높이 | 코뿌리·코밑 주석 위치 합의 필요. 현재 구현 없음 |
| 코끝이 둥글다 | 정면 코끝 윤곽의 둥근 정도 | 현재 rounded/tapered 파일럿에 해당. 코 폭·돌출과 독립 |
| 코가 높다 | 기준 얼굴 평면 대비 돌출량 | 측면 또는 보정된 깊이 정보. 정면 2D만으로 확정 보류 |
| 얼굴이 넓다 | 얼굴 폭 / 얼굴 기준 높이 | 상대 형태. 실제 머리 크기와 구분 |
| 얼굴이 크다 | 실제 얼굴 폭·높이(mm)를 각각 정의 | 일반 가이드 셀카에서는 판정 불가. 크기 보정 필요 |
| 눈썹이 굵다 | 눈썹 털 영역의 두께 / 눈 가로 길이 | 털 영역 분할 또는 사람이 윤곽 주석. 랜드마크만으로 털 밀도 확정 불가 |
| 눈썹이 눈에 가깝다 | 눈썹 하단~위눈꺼풀 거리 / 눈 가로 길이 | 측정 위치·표정 통일. 중앙·안쪽·바깥쪽 값을 별도 보존 |
| 귀미 | 굵기와 눈 가까이 내려오는 형태의 복합 조건 | 현재 모델 클래스에 없음. 유형 간 겹침·검수자 일치도 확인 필요 |

현재 features.py의 nose_width_face = distance(98,327)/distance(234,454)는 기존 랜드마크 기반 대리 지표다. 점이 실제 콧방울 최외측·광대 최외측과 일치한다는 검증은 아직 없다. 해부학적 콧방울 폭·광대 폭으로 명명하거나 mm로 환산하지 않는다. face_visible_height_width의 점10도 실제 헤어라인 점으로 간주하지 않는다. 동일 측정 정의로 반복성을 평가한 후 확정한다.

## 3. 크다/보통/작다의 경계

먼저 연속 비율을 저장한다. 넓음·중간·좁음은 프로젝트 비교 집단 안에서의 상대 구간으로 정의한다. 초기 실험 후보는 학습 집단의 P25/P75이며, 고전 관상이나 한국인 전체의 공인 기준이 아니다. 아직 수치 경계를 확정하지 않는다.

기준 집단은 승인된 한국인 자료의 촬영 조건을 통일한 표본으로 정한다. 한 사람이 여러 장 있어도 1명 가중치가 되도록 사람별 대표값을 사용한다. 집단 구성과 기준 버전을 기록한다. 기존 FRLL 102명의 분포를 한국인 기준으로 사용하지 않는다. 학습 집단에서만 경계를 산출·동결하고 검증/시험 집단마다 다시 계산하지 않는다.

반복 촬영의 측정 변동으로 경계 주변 보류 구간을 결정한다. 표정·가림·자세로 기준점을 확인할 수 없거나 반복 측정이 경계를 오가면 '판정 보류' 또는 연속값만 제공한다. 분류기 정확도와 별개로 측정 오차·반복성·검수자 간 일치도를 평가한다.

## 4. 가이드 촬영과 절대 크기

얼굴을 화면 타원에 맞추게 하면 사용자가 거리 자체를 바꾸므로 서로 다른 실제 얼굴 크기도 같은 픽셀 크기가 된다. 가이드는 자세·가림·프레이밍 보조 수단이며 길이 단위의 기준자가 아니다.

고정 카메라라도 같은 렌즈·초점거리·줌·출력 해상도와 실제 얼굴 평면까지의 거리가 확인되어야 한다. 의자나 바닥 표시만 고정하면 머리의 앞뒤 움직임이 남는다. 실제 mm가 필요하면 카메라 보정과 깊이/거리 측정, 또는 얼굴 측정 평면에 가까운 알려진 크기의 기준물을 이용한다. 얼굴은 평면이 아니므로 기준물과의 깊이 차이 오차도 검증한다. 전용 장치 또는 실측값으로 검증되지 않은 추정은 실제 크기로 표시하지 않는다.

일반 서비스 1차 범위는 상대 비율과 윤곽이다. 정면·무표정, 머리 회전 최소화, 눈썹·얼굴선 가림 제거, 미용 필터 해제, 균일한 조명을 안내한다. 얼굴 해상도·자세 허용치는 반복 촬영 실험으로 정한다. 임의의 각도를 검증된 기준처럼 제시하지 않는다. MediaPipe의 정규화 좌표와 추정 깊이는 자체로 실측 mm가 아니다.

## 5. 모델 입력과 작업 순서

CNN은 코끝·눈썹 등 복잡한 외형을 학습한다. 상대 크기는 전체 얼굴 이미지와 정규화 비율을 입력으로 보존해야 한다. 방법은 (a) 형태 CNN 결과와 별도의 비율 판정을 병합하거나 (b) 부위 CNN 특징과 비율 벡터를 결합해 학습하는 것이다. 모든 특성을 다시 수작업 if문으로 분류할 필요는 없지만 레이블의 뜻과 비교 기준은 어느 방식에서도 정의해야 한다.

진행 순서: 문헌 해석 사전과 형태 요구조건 구축 → 측정·주석 지침과 대표/경계/보류 예시 → 소규모 독립 중복 검수 → 재현 가능한 레이블 확정 → 본 레이블링 → 학습·평가 → 유형 조건을 충족한 경우에만 해당 문헌 설명 참조.

사진 전 단계에서 끝낼 수 있는 것은 문헌 의미·출처·논리적 형태 조건·측정 절차의 초안이다. 실제 수치 경계, 분류 가능성, 촬영 허용 범위, 정확도는 사진으로 검증해야 한다. '귀미는 당연히 잘 분류된다'는 아직 검증되지 않은 가정이다.
