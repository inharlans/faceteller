FaceTeller 분류 모델 선정 근거 — 최종 ResNet-18 단일계열

결정
서비스의 부위별 CNN은 모두 ImageNet 사전학습 ResNet-18을 미세조정한 모델이다.
12개 부위에 각각 별도 가중치를 쓰며, 다른 계열을 함께 평균하는 앙상블은 사용하지 않는다.
VGGT 깊이 분석과 MediaPipe 특징점 추출은 별도 역할이다.

구조와 과제의 관계
입력은 얼굴 전체에서 부위를 찾는 장면이 아니라, 이미 위치를 검출하고 눈 중심 기준으로
정렬한 부위 영상이다. 부위의 윤곽·비율·질감 차이를 분류하는 비교적 좁은 과제이므로,
우선 ResNet-18의 얕은 구조로 필요한 표현력을 확보하는 접근을 택했다.
잔차 연결 y=F(x)+x는 역전파 경로를 제공하여 최적화를 돕는다. 작은 자료에서 과적합이
자동으로 사라진다는 뜻은 아니다. 사전학습 가중치를 재사용하는 이유는 실제 학습 인물이
270명으로 제한되어 있기 때문이다. 사전학습은 다른 후보도 지원하므로 ResNet만의 장점은 아니다.

실제 비교로 확인한 범위
동일 절차의 기존 5부위·15헤드 비교에서 선택 집합 macro-F1은 다음과 같다.
  ResNet-18        0.722334
  EfficientNet-B0  0.711364
  ConvNeXt-Tiny    0.655870
세 단일 후보 중 ResNet-18이 가장 높았다. 모든 CNN 중 최적이라는 증명은 아니다.
원래의 3계열 앙상블 선택 점수는0.741238이었다. 이 기록은 보존하고, 사용자의 단일계열
운영 결정에 따라 현재 배포를 바꿨다. ResNet이 원래 앙상블 선택 규칙에서 이겼다고 쓰지 않는다.
그 비교는 기존 전처리와15헤드에 대한 결과이며, 최종41헤드의 정확도로 재사용하지 않는다.
최종41헤드는 별도 시험 산출물 outputs/release/test_metrics.json에서 확인한다.

처리 비용에 대한 표현
ResNet-18을 모든 CNN 중 최소 연산·최소 메모리 모델이라고 표현하지 않는다.
EfficientNet-B0처럼 파라미터와 이론적 연산량이 더 적은 모델도 있고, 실제 지연은 장치와
연산 구현에 영향을 받는다. 이번 결정의 근거는 과제 적합성, 비교한 단일 모델의 성능,
하나의 계열로 학습·배포·보정을 관리하는 단순성이다. 실제 서비스 시간은400명 HTTP 실측으로 보고한다.
