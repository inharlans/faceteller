FaceTeller 정면 사진·측정선 사용 안내 (2026-10-15)

사용 방법
1. 분석 결과에서 ‘사진과 측정선 표시’를 켭니다.
2. 처음에는 눈썹 길이, 눈꼬리 기울기, 코 너비, 입 너비를 표시합니다.
3. ‘전체 19개’ 또는 개별 항목을 선택하면 다른 측정선도 볼 수 있습니다.
4. 결과지 미리보기와 인쇄에도 선택한 사진·선이 들어갑니다.
눈썹 영역을 잡지 못한 사진은 해당 선을 생략하므로 표시 가능한 개수가 줄어듭니다.
사진 표시는 기본으로 꺼져 있습니다.

QA할 때 볼 부분
- 눈썹 선의 시작과 끝이 실제 눈썹털의 시작·끝에 맞는지 봅니다.
- 눈꼬리, 코 양 끝, 입 양 끝의 선이 해당 위치에 맞는지 봅니다.
- 선이 맞는데 분류가 이상하면 측정 위치와 분류 모델을 나누어 확인할 수 있습니다.
- 선 자체가 틀리면 위치점 추출 또는 눈썹 영역 추출부터 확인해야 합니다.
- 눈썹의 짧음·김은 눈 가로 대비 비율을 비교 자료와 비교한 표현입니다.

확인한 내용
새 모델을 적용한 실제 사진 업로드와 브라우저 검사 통과.
400명 각각 정면·좌측·우측 원본 사진을 넣은 검사: 응답 오류 0건, 측정선 좌표 구조·사진 범위 검사 400명 통과.
395명은19개, 눈썹 측정이 보류된5명은17개 선 묶음이 제공됐습니다.
로컬 요청부터 결과까지 평균1.43초, 최댓값1.70초였습니다. 촬영 대기·외부 업로드 시간은 제외합니다.
사진·선 표시 영역 차이 0픽셀. 기본 4개·전체19개 선택, 켜기·끄기 및 인쇄 미리보기 확인.
사진을 숨긴 실제 결과지는 A4 1페이지이며 원문·번역 4개가 모두 포함됨을 확인했습니다.
실제 사진을 켠 상태는 화면과 인쇄용 DOM에서 확인했으며, 얼굴이 든 검사용 PDF는 저장하지 않았습니다.
카메라 입력 경로에 녹화 프레임을 넣었을 때, 같은 사진 업로드와 45개 항목 판정·점수가 같았습니다.
카메라 경로 검사는 실제 촬영 하드웨어를 직접 사용한 검사가 아닙니다.

선의 의미
눈썹 길이·꼬리 선은 실제 사진에서 분리한 눈썹털 영역을 바탕으로 표시합니다.
다른 선은 얼굴 특징점에서 계산한 위치와 길이·각도입니다.
CNN이 어디에 주목했는지를 보여주는 지도는 아닙니다.
정확한 털 영역을 얻지 못하면 기존 얼굴 기준선으로 대체하지 않고 생략합니다.
선이 표시된다는 것만으로 분류가 정확하다는 뜻은 아닙니다. 특히 눈썹 길이 분류는 추가 확인이 필요합니다.

사진 처리
현재 결과의 정면 사진만 브라우저 메모리에 남습니다.
다시 시작하거나 페이지를 벗어나면 현재 사진을 정리합니다.
사진과 좌표를 이용 기록으로 자동 저장하지 않습니다. 진단 JSON에도 사진·측정선 좌표를 넣지 않습니다.
사용자가 사진 표시를 켠 채 PDF로 저장하면 그 PDF에는 사진이 포함됩니다.
