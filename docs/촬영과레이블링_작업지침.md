# 촬영·형태 주석 작업지침 v2

2026-09-22 / 사진 검증 전 초안. 이 문서의 측정 실험 설계와 표본 수 제안은 프로젝트 제안이며 확립된 관상 표준이 아니다.

## 촬영 목적과 허용 범위

1차 서비스는 정면 사진의 외형과 상대 비율을 관찰한다. 실제 얼굴 크기(mm), 코 돌출량, 성격·지능·건강·재산·미래는 정면 사진의 정답 레이블에 넣지 않는다. 문헌 해석은 별도 사전으로 조회한다.

촬영 화면에는 다음을 안내한다: 정면·무표정, 입을 편하게 다물기, 눈을 억지로 크게 뜨지 않기, 눈썹과 얼굴선 가림 제거, 미용 필터·얼굴 보정 끄기, 균일한 조명. 타원 가이드는 프레이밍과 회전 확인용이며 실제 얼굴 크기의 자가 아니다.

거리 통제 실험에서는 휴대전화/카메라 모델, 렌즈, 줌, 출력 해상도, 카메라 높이, 카메라에서 얼굴 기준면까지의 거리, 조명, 좌우 반전 여부를 기록한다. 카메라 위치만 같고 얼굴이 움직이면 동일 거리로 간주하지 않는다. 줌으로 같은 화면 크기를 맞춰도 원근 왜곡은 거리 변화와 같지 않다.

가까운 촬영은 코 폭/얼굴 폭 비율도 변형할 수 있다. Ward 등(2018)의 수학적 모델은 촬영 거리의 영향을 설명한다. 그 논문의 특정 거리에서의 결과를 우리 기기·참여자 전체에 대한 정확도 보증으로 사용하지 않는다. https://doi.org/10.1001/jamafacial.2018.0009

## 수집 실험 제안

- 초기 운영 검증 제안: 동의와 사용권을 갖춘 20명, 동일 조건에서 자세를 풀고 다시 맞추는 독립 촬영 3회. 최소 필요 표본의 통계적 보증이 아니라 실행 가능한 1차 점검안이다.
- 정면 기준 촬영 외에 카메라·거리·자세를 한 번에 하나씩 바꿔 비교한다. 가까운 셀카와 떨어진 촬영을 같은 분포로 섞지 않는다. 거리 후보는 장비·해상도 확보 가능 범위에서 정하고 실제 거리를 기록한다.
- 같은 영상을 연속 캡처한 프레임만으로 재현성을 검증하지 않는다. 반복 셋은 가능하면 촬영 세션을 분리한다.
- FRLL의 무표정/미소 쌍은 표정 민감도 점검용이다. 같은 조건 반복이 아니므로 측정 오차나 중립 반복 신뢰도의 근거로 사용하지 않는다.
- 기존 FRLL이 한국인 기준 표본을 대체하지 않는다. K-FACE도 촬영 거리가 확인되지 않으면 해당 제한을 기록한다.

## 형태 주석 절차

1. 촬영 품질을 먼저 검수한다. 가림·블러·미소·회전·필터 의심·부위 누락을 각각 기록한다. 미측정/판정불가를 중간형으로 처리하지 않는다.
2. 검수자는 유형명·길흉 해석·다른 검수자의 값을 보지 않고 관찰 가능한 외형부터 독립 주석한다. 좌우는 피사체 기준이다.
3. 같은 얼굴 전체와 원본 해상도 부위 확대를 같이 본다. crop 확대 크기로 '큰 코'를 정하지 않는다.
4. 정량 항목은 동일 기준점·분모로 연속값을 저장한다. 털 영역을 재는 눈썹 두께는 랜드마크 두께와 구별한다. 모호한 기준점은 위치 불확실성을 기록한다.
5. 첫 20명 표본은 적어도 검수자 2명이 독립 검수하는 운영안을 사용한다. 일치율, 범주별 혼동, Cohen's kappa를 함께 보고 드문 범주의 수와 보류율도 보고한다. 특정 kappa 통과값을 근거 없이 공인 기준처럼 설정하지 않는다.
6. 불일치 사유를 조정하되 원래 두 기록은 보존한다. 이 기록은 앞으로 받을 실제 사람 검수이며 AI가 검수자 2명을 가장해 채우지 않는다.
7. 승인된 데이터의 원본 예시는 로컬 검수 저장공간에만 둔다. 공개 가능한 예시는 별도 사용권이 있는 사진이나 명확히 합성 예시라고 표시한 도식으로만 만든다.
8. 유형별 대표/경계/반례의 실제 사진은 원문 조건과 두 검수자의 판정이 확인된 후 선정한다. 현재 자료에서 전통 유형의 정답 사진을 임의 지정하지 않는다.

## 수치 경계와 보류

학습 사람 단위 대표값에서 P25/P75 등 후보를 만들고 별도 검증 집단으로 의미와 안정성을 검토한다. 같은 사람의 수십 장을 수십 명처럼 세지 않는다. 시험 집단을 경계 설정에 사용하지 않는다.

반복 측정에서는 사람별 범위·표준편차, 조건별 차이, 검수 기준점 차이를 확인한다. 개발 단계의 반복 자료로 오차 폭을 정하고 동결한다. 새 측정값의 오차 구간이 경계를 가로지르면 보류한다. 동점이 많아 P25=P75인 항목은 3개 구간 분류를 만들지 않는다. 기준 집단·기기·정의 버전이 다르면 경계를 재사용하지 않는다.

현재 배포된 측정은 값만 보여주고 크다/작다를 미확정으로 표시한다. FRLL 백분위 파일은 파이프라인 확인을 위한 기술통계이며 한국인 또는 서비스의 판정 경계가 아니다.

## 전체 유형과 문헌 연결

전체 유형의 조건이 정해지지 않았으면 '일부 형태 표현 참고'를 유지한다. 귀미처럼 눈썹 두께와 눈 사이 간격이 함께 필요한 유형은 두 관찰 항목을 분리해 검수한다. 눈썹이 굵다는 사실만으로 귀미를 확정하지 않는다.

상충·불명확한 구절은 문헌 검토자가 판본 또는 원본 이미지를 대조한다. 유엽미의 眉粗, 앵도구의 口大, 호비의 蘭臺廷尉亦須無, 후구의 喜·破竹, 복선구의 兩脣牛肉 등이 검토 대상이다. 이것이 모두 오탈자라고 단정하거나 통념에 맞게 원문을 고치지 않는다.
