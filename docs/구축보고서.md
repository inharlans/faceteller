작성: 2026-09-21. 범위: 연결된 세 기획 대화의 데이터 수집·문헌 정의·부위별 분류 모델 구상을 바탕으로 로컬 파일럿을 구현했습니다.

## 데이터 조사와 채택 이유

조사는 Exa에서 4개 검색으로 20개 검색 결과를 확인하고, 공식 배포처·저자 페이지·문헌 원문·도구 공식 문서로 검증했습니다. 검색 결과 수는 독립 자료 수가 아니며 중복과 무관한 결과는 채택하지 않았습니다. 일부 초기 검색에는 일반 웹 검색을 사용했습니다.

| 후보 | 확인한 사실 | 실제 처리 |
|---|---|---|
| [FRLL London Set](https://figshare.com/articles/dataset/Face_Research_Lab_London_Set/5047666/5) | 성인 102명, 1350×1350, CC BY 4.0; 연구용 원본·변형·연구 소개에 대한 서명 동의 설명 | 공식 API로 무표정/웃는 정면 ZIP 수신. 공개 연구 파일럿으로 채택 |
| [AI Hub 한국인 안면 이미지](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=83) | 원래 1,000명, 각도·조명 등 반복 촬영. 개인정보 활용 동의 갱신에 따라 일부 공개 | 비로그인 HTTP와 실제 브라우저 모두 확인. 샘플도 로그인으로 연결, 승인 전 원본 미수신 |
| [CelebA](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html) | 202,599장, 10,177명, 40속성. 비상업 연구 조건과 원본 재배포 제한 | 얼굴 속성 레이블 참고. 상용 서비스 주 자료로 무단 채택하지 않음 |
| [Chicago Face Database](https://www.chicagofaces.org/download/) | 본체 597명, 별도 확장 세트. 연구용 신청 양식 및 이용 제한 | 물리적 얼굴 측정 정의 참고. 신청자 정보를 임의 작성하거나 신청 메일 발송하지 않음 |

AI Hub 페이지에 공통으로 삽입된 국방·안심존 안내를 이 데이터셋이 반드시 국방 데이터라는 뜻으로 읽지 않았습니다. 실제 자료의 공개 공지와 다운로드 승인 안내를 근거로 구분했습니다. 현재 공개 범위의 실제 인원은 원본을 받은 뒤 산출해야 합니다.

### FRLL 다운로드 증거

| 파일 | 바이트 | 공식 MD5 |
|---|---:|---|
| neutral_front.zip | 33,860,607 | 236c1c94defbb34a79074b195841cfd6 |
| smiling_front.zip | 53,522,950 | 9fe48bb112543daf734f1016e93d2e70 |
| london_faces_info.csv | 2,074 | 52e9d142812130f0b19af168260fb160 |

세 파일 모두 크기와 MD5가 일치합니다. 이미지별 SHA256과 배포 URL은 원본/파생 manifest에 있습니다. 메타데이터의 자기보고 인구통계 정보는 사진에서 추정하지 않았으며 분류 목표로 사용하지 않았습니다. 매력도 평가 파일은 이 프로젝트에 필요하지 않아 받지 않았습니다.

## 문헌과 레이블을 연결하는 방식

사용자가 주신 [CText 神相全編](https://ctext.org/wiki.pl?if=gb&chapter=905153&remap=gb) 페이지는 이번 환경에서 실제 수신에 성공했습니다. 다만 103개 유형 사전의 직접 출처는 『고금도서집성』 예술전 633·634권의 『신상전편』 수록 전사본입니다. CText와 같은 판본이라고 단정하지 않았습니다. 원문 HTML·텍스트·수신 날짜·해시를 저장했습니다.

각 항목에는 문헌 ID, 원문명, 한국어 검색명, 실제 원문 절, 형태 설명, 판정 한계, 번역 검수 상태, 출처 URL을 넣었습니다. 이전 대화의 첨부 ZIP 자체를 복원한 것은 아니며 이번 원문 수신을 바탕으로 재구축했습니다. 따라서 이전에 언급된 100개 ID와 호환된다고 주장하지 않습니다.

실제 대조에서 다음 문제가 확인됐습니다.

- 鳳眼의 `鳳眼波長`은 긴 눈매 묘사입니다. “반드시 눈꼬리가 +6도” 같은 임계값은 본문에 없습니다.
- 獅眼은 큰 눈과 굵은 눈썹의 조합입니다. 눈 한 조각만으로 전체 유형 정답을 만들 수 없습니다.
- 柳葉眉는 이 전사본에서 `眉粗帶濁濁中清`입니다. 가늘다는 현대 통념으로 바꾸지 않았습니다.
- 櫻桃口는 이 전사본에서 `口大`입니다. 작은 입으로 임의 수정하지 않았습니다.
- 羅漢眉·交加眉 등은 해당 짧은 절만으로 구체적 형태 조건이 부족합니다.
- 鼻의 높이·굴곡·돌출, 눈의 깊이, 움직이는 시선·눈물·기운 같은 조건은 정면 한 장으로 신뢰성 있게 확정할 수 없습니다.

103개 항목을 모두 강제 분류 클래스로 쓰면 번역 모호성·복합 조건·사진 관찰 한계가 모델의 정답에 섞입니다. 그래서 현재 CNN은 관찰 가능한 단순 형태를 학습합니다. `data/literature_links.json`의 8개 연결은 외형 표현이 부분적으로 겹친다는 문헌 참조이며, 전통 유형 판정이나 사람의 성격·운명 풀이가 아닙니다.

## 1차 사진 레이블의 정의와 분포

사진 102장을 얼굴 확대 시트 9개로 전부 확인했습니다. 이후 가림·부위 잘림 문제를 별도 crop QA 시트로 확인했습니다. 작성 주체는 AI이며 두 번째 독립 검수자로 세지 않습니다.

| 모델 | 클래스별 부위 이미지 수 | 판정 기준 |
|---|---|---|
| 눈 | narrow 18 / intermediate 110 / rounded 76 | 가로 대비 세로 개방의 육안 분류 |
| 눈썹 | straight 78 / arched 94 / angled 28 | 보이는 눈썹 띠의 중심선 |
| 코 | rounded 80 / tapered 22 | 정면에서 보이는 코끝 윤곽 |
| 입 | thin 17 / medium 49 / full 36 | 입 너비 대비 보이는 입술 붉은 부분의 두께 |
| 얼굴형 | oval 46 / round 9 / angular 22 / long 21 | 사진에서 보이는 지배적 외곽 형태 |

양쪽 눈·눈썹은 같은 사람에게서 나온 상관된 표본입니다. 204개 눈을 204명의 눈으로 보지 않습니다. 좌우 이름은 피사체 기준입니다. 미소·화장·수염·앞머리·기울기 등 관찰 메모를 남겼습니다. 8개 unknown은 003과 143의 양쪽 눈썹, 037·070·092·143의 얼굴형입니다.

측정값은 MediaPipe 좌표로 계산한 추정치입니다. 예를 들어 코 너비는 98–327점 거리 / 얼굴 234–454점 거리, 입 너비는 61–291점 거리 / 같은 얼굴 너비입니다. 눈 틈 비율은 모서리 거리 / 중앙 눈꺼풀 점 거리입니다. 얼굴 길이는 10–152점이므로 실제 머리카락 경계의 삼정 측정이 아닙니다. 자동 측정으로 초벌 육안 정답을 생성하지 않았습니다.

## 학습과 검증

장치에서 확인한 GPU는 **RTX 3070 8GB**입니다. 기획 대화의 4080으로 실행한 것이 아닙니다. Python 3.12, PyTorch 2.11.0+cu128, torchvision 0.26.0+cu128, MediaPipe 1.0.1에서 실행했습니다. 전체 설치 버전은 requirements-lock.txt에 저장했습니다.

최초 해시 기반 무작위 분할에는 일부 얼굴형의 시험 표본이 0개였습니다. 이 결과는 폐기했습니다. 최종 v2 분할은 seed 20260921, 전체 레이블을 이용한 **클래스 포함 여부만**을 기준으로 선택했습니다. 모델 출력이나 정확도를 최적화해 분할을 선택하지 않았습니다. 각 클래스가 검증·시험에 최소 2명, 학습에 최소 3명을 갖도록 했습니다. train/val/test는 72/15/15명입니다.

이는 작은 파일럿에서 누락 클래스를 없애는 방법이며 독립 외부 평가를 대신하지 않습니다. 첫 시험 결과를 이미 확인한 이력이 있으므로 최종 수치도 탐색적 결과로만 취급합니다. 실제 서비스 검증에는 새로운 한국인·독립 검수 데이터가 필요합니다.

각 부위 모델은 ImageNet 사전학습 MobileNetV3-Small, 224×224 비율 유지 패딩, 좌측 눈·눈썹 좌우 정규화, 마지막 3개 feature block 및 classifier 미세조정을 사용했습니다. 작은 배치로 BatchNorm 통계가 흔들리지 않도록 고정했습니다. 학습 클래스 빈도의 역수로 손실 가중치를 정하고 12epoch 중 검증 macro F1이 가장 높은 epoch를 선택했습니다. 시험 세트로 epoch를 선택하지 않았습니다.

| 최종 v2 모델 | 시험 정확도 | Macro F1 | 다수 클래스 기준 정확도 |
|---|---:|---:|---:|
| 눈 | 56.7% | 0.420 | 53.3% |
| 눈썹 | 73.3% | 0.533 | 46.7% |
| 코 | 80.0% | 0.720 | 73.3% |
| 입 | 53.3% | 0.522 | 33.3% |
| 얼굴형 | 60.0% | 0.442 | 46.7% |

전체 정확도가 높아도 작은 클래스 실패가 가려질 수 있어 macro F1과 클래스별 confusion matrix를 함께 저장했습니다. 눈 모델은 다수 클래스 기준과 차이가 작습니다. 이 모델들을 관상 유형 판정 정확도라고 부르면 안 됩니다. 시험 레이블도 같은 AI 검수자의 관례이며 독립 정답이 아닙니다.

### 실제 검증 내용

- 원본 204개의 이미지 디코딩·SHA256, 부위 1,428개의 이미지 디코딩·크기·경계 검증.
- 478점 존재, 706개 학습 레이블의 유효 범주, unknown/웃는 사진 학습 제외, 같은 사람의 split 중복 0건 확인.
- 공식 189점 템플릿의 양쪽 동공 중심과 MediaPipe 홍채 중심 비교: 102장, 동공간 거리로 정규화한 평균 위치 오차의 중앙값 0.0166, 95백분위 0.0256. 동공 부근의 제한적 진단이며 모든 랜드마크의 정확도 보장은 아닙니다.
- 같은 사람의 웃는/무표정 비교: 입술 두께/입 너비의 중앙 변화 -0.0659, 오른눈 가로/세로비의 중앙 변화 +0.2616. 표정 제한이 필요한 근거이며 독립 정답에 대한 정확도는 아닙니다.
- API 테스트 6개: 실제 사진 추론·원본 미저장, 비이미지/얼굴 없는 이미지 처리, media 조회, 외부 출처 수정 거절, 검수 저장·충돌·잘못된 레이블 거절, 수정 없는 엑셀 가져오기.
- 수정 테스트는 임시 폴더에서만 실행했습니다. 이를 실제 인간 검수 1건으로 세지 않았습니다.
- 엑셀 집계 입력 변화·복원, 수식 오류 검색, 시트별 레이아웃 렌더 확인. XLSX에 사진 102개와 위치 anchor가 포함됨을 재가져오기 및 내부 파일 검증으로 확인했습니다. 제공된 엑셀 미리보기 렌더러가 그림을 표시하지 않아 **Microsoft Excel 실제 화면의 그림 렌더는 미확인**입니다. 사진은 웹 작업대에서 직접 확인 가능합니다.

## 남아 있는 실제 막힘

1. **AI Hub 계정과 다운로드 승인**: 이 컴퓨터의 브라우저도 비로그인 상태입니다. 샘플 링크가 로그인을 요구합니다. 사용자에게 승인 계정 여부를 물었으며 비밀번호를 요구하지 않았습니다. 권한 승인을 우회하거나 받은 것으로 처리하지 않았습니다.
2. **독립 레이블 검수**: AI 단일 검수만으로 팀원 간 합의나 관상 전문가 판정을 대신할 수 없습니다. 경계 사례·가림·화장을 포함한 교차 검수와 일치도 측정이 남았습니다.
3. **전통 유형 정답**: 번역과 판본·복합 조건이 해결되지 않은 유형은 승인하지 않았습니다. 봉안·용안 103클래스 정답이 완성됐다고 말할 수 없습니다.
