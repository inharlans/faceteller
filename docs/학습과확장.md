# 부위별 CNN 학습과 데이터 확장

## 현재 체크포인트 사용

`models/pilot/eye.pt`, `brow.pt`, `nose.pt`, `mouth.pt`, `face.pt`에 가중치·클래스 순서·스키마 버전·평가 정보를 함께 저장했습니다. 체크포인트는 외형 실험용입니다. 새 사진 분석은 로컬 API가 이 파일을 읽어 실행합니다. 전통 이름이나 성격·운명을 예측하지 않습니다.

형태 클래스는 `data/label_schema.json`이 기준입니다. 눈썹 `angled`는 눈썹 띠의 방향 전환을 뜻하며 고전의 `劍眉`와 같지 않습니다. 모델을 바꿀 때 임의로 클래스 순서를 바꾸지 마세요.

## 환경 복원

현재 작업 폴더에는 `.venv`가 이미 준비되어 있습니다. 다른 컴퓨터에서는 Python 3.12로 가상환경을 새로 만들고 같은 버전을 설치합니다. 다음은 이 컴퓨터에서 검증한 CUDA 12.8 wheel 조합입니다. GPU/드라이버가 다르면 [PyTorch 공식 설치 안내](https://pytorch.org/get-started/locally/)에서 호환 조합을 확인하세요.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt --extra-index-url https://download.pytorch.org/whl/cu128
```

부트스트랩에 네트워크가 필요하고 패키지·모델 다운로드가 발생합니다. 원본 사진은 출처 배포 ZIP 그대로 보존하세요. `.venv`나 DLL을 프로젝트 코드로 Git에 넣지 않습니다.

## 재현 명령

프로젝트 루트에서 실행합니다.

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:TORCH_HOME=(Join-Path (Get-Location) 'models/torch_cache')
.\.venv\Scripts\python.exe scripts/download_frll.py
.\.venv\Scripts\python.exe scripts/fetch_sources.py
.\.venv\Scripts\python.exe scripts/prepare_data.py
.\.venv\Scripts\python.exe scripts/build_literature.py
.\.venv\Scripts\python.exe scripts/finalize_labels.py
.\.venv\Scripts\python.exe scripts/export_training_set.py
.\.venv\Scripts\python.exe scripts/verify_dataset.py
.\.venv\Scripts\python.exe -m facework.training --pilot --task all --epochs 12 --batch-size 16
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

AI 1차 레이블을 이용한 실험임을 명시하기 위해 `--pilot` 옵션을 요구합니다. 옵션 없이 인간 검수 미완료 데이터로 학습하려 하면 종료합니다. GPU가 없어도 `--device cpu`로 실행 가능하지만 속도는 달라집니다.

특정 부위만 실행하려면 `--task eye`, `--task brow`, `--task nose`, `--task mouth`, `--task face`를 사용합니다. 현재 정식 실행은 `all` 순서로 seed를 고정했습니다. 별도 부위 단독 실행 시 난수 소비 순서가 달라 초기화가 동일하지 않을 수 있습니다. CUDA의 완전한 비트 단위 결정성을 보장하는 설정은 아닙니다.

## ImageFolder 형태

`data/derived/training_set_location.json`에 현재 내보낸 버전 경로가 있습니다. 디렉터리는 다음 형식입니다.

```text
classified/<manifest hash>/eye/train/narrow/frll_...__eye_right.jpg
classified/<manifest hash>/eye/val/rounded/...
classified/<manifest hash>/eye/test/intermediate/...
classified/<manifest hash>/nose/train/rounded/...
```

원본 crop과 로컬 hard link를 사용해 중복 저장을 줄입니다. 원본 파일 내용은 수정하지 마세요. 다른 저장장치에서는 복사로 대체합니다. 레이블 변경 후 다시 export하면 새로운 manifest hash 버전이 만들어집니다. 예전 버전은 자동 삭제하지 않습니다.

일반 `ImageFolder`는 각 split 안의 디렉터리 이름을 정렬해 클래스 순서를 정합니다. 이 프로젝트 checkpoint의 순서는 스키마의 순서이므로 기존 checkpoint와 일반 ImageFolder 출력 인덱스를 혼용하지 마세요. 제공한 학습기는 CSV manifest와 클래스 이름으로 매핑합니다. 좌측 눈·눈썹은 입력할 때만 mirror하며 export 이미지에는 반영하지 않습니다.

## 평가 원칙

- 한 사람이 여러 사진·양쪽 부위로 등장해도 모두 같은 split에 둡니다.
- 데이터 증강은 학습 세트에만 적용합니다. 회전·원근·세로/가로 왜곡은 레이블을 바꿀 수 있으므로 무작정 넣지 않습니다.
- 원형·길쭉함을 배우는 입력을 정사각형으로 찌그러뜨리지 않습니다. 비율 유지 후 패딩합니다.
- 새로운 전처리·증강·구조 선택은 검증 세트로 결정합니다. 시험 수치를 보고 반복 조정하면 별도의 미사용 시험 데이터가 필요합니다.
- accuracy 외에 class별 recall, macro F1, confusion matrix와 unknown 비율을 봅니다.
- 15명 시험 세트는 작은 파일럿입니다. 실제 서비스 성능을 보장할 표본 수가 아닙니다. 눈·눈썹 좌우를 서로 독립된 30명으로 계산하지 않습니다.
- 새 데이터의 독립 검수 없이 AI 레이블에 대한 점수를 인간 정답 정확도로 바꾸어 부르지 않습니다.

## K-FACE를 이어 붙인 결과 (v2)

K-FACE High_Resolution 400명을 받아 v2를 구축했습니다. 참여자 ID는 배포 ZIP 이름(참여자별 ZIP)에서 가져오며, 조건 코드(S/L/E/C)의 의미는 표본 확인과 MediaPipe 통계로 검증했습니다. v1(FRLL) 레이블 스키마를 그대로 쓰지 않고 `data/label_schema_kface_v2.json`의 21개 특징으로 확장했습니다. 학습은 `python -m facework.kface_training --part all`, 평가는 `python scripts/kface_evaluate.py`입니다. 방법·성능·한계는 `docs/K-FACE_v2_구축보고서.md`를 보세요.

## 팀 검수

한 명이 원문·정의·사진을 함께 확인한 후, 두 번째 사람이 첫 레이블을 보지 않고 같은 표본을 판정하는 흐름이 필요합니다. 현재 웹 도구는 원본 1차 레이블을 보여주는 수정 도구이므로 블라인드 이중 검수 시스템이라고 부르지 않습니다. 독립 검수본의 `annotation_id`를 맞춰 일치율과 Cohen kappa 등을 별도 계산해야 합니다.

문헌형 `봉안/용안/...` 모델을 만들려면 각 유형의 관찰 조건과 대표 예시를 먼저 승인해야 합니다. 모호한 유형은 복수 후보 또는 판정 불가를 허용하고, 여러 부위·측면이 필요한 경우 입력도 그 조건에 맞게 바꿉니다. 형상만으로 성격·도덕성·지능·건강·운명 정답을 만들지는 않습니다.
