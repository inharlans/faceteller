# 문헌 해석·측정 정의 v2 작업 내역

2026-09-22

## 완료한 범위

- 확보한 『고금도서집성』 633·634권의 눈썹 24, 눈 39, 코 24, 입 16 유형, 총 103건에 한국어 해석 요약을 작성했다. 주제별 문헌 평가, 근거 구절, 원문, 출처, 검토 사항을 연결했다. 모든 근거 구절이 저장 원문에 실제 포함되는지 검사했다.
- 103유형의 형태 설명, 필요한 사진·관찰 입력, 판정 보류 사유를 연결했다. 기존 8개의 형태 참고 연결은 부분 일치라는 의미를 유지한다. 이름만으로 새로운 형태 조건을 만들어 넣지 않는다.
- 측정 정의 17개를 작성했다. 현재 계산 가능한 랜드마크 대리 지표는 11개다. 코 길이, 코 돌출, 실제 얼굴 크기, 눈썹 털 두께, 눈썹-눈 간격, 눈썹 털 밀도 6개는 입력과 정의를 명시하되 구현 완료로 표시하지 않았다.
- FRLL 학습 분할 무표정 72명으로 11개 비율의 P25·중앙값·P75를 계산했다. 사람별 중앙값으로 동일인의 과도한 가중치를 방지하며 검증·시험 분할은 사용하지 않는다. 한국인 기준이나 서비스 판정에 적용하지 않는다.
- 촬영·독립 주석·반복 실험·경계 보류 지침, 사람 검수 입력 양식, 반복 촬영 입력 양식, 문헌 검토 입력 양식을 만들었다.
- 기존 작업대의 문헌 사전에 해석·주제·평가 필터와 유형별 판정 요건을 추가했다. 형태 참고 항목을 누르면 해당 문헌 사전을 볼 수 있다. 측정 정의 탭과 실제 사진 분석의 비율 표를 추가했다.
- 서버 없이 여는 검색 가능한 HTML 사전을 제공한다. CSV와 JSON도 함께 제공한다.

## 해석의 완료 수준

103건의 초벌 요약이 모두 작성되었다. 완역·원본 교감·독립 전문가 검수는 아니다. 주제별 분류는 기록한 주장에 대한 표시이며 미분류 주제가 원문에 전혀 없음을 보증하지 않는다. 인격·성적 품행·지능·질병·죽음에 관한 역사적 주장은 개인 사진의 특성이나 운명 정답으로 사용하지 않는다.

원문이 모호한 항목도 빈 값을 정상 해석으로 가장하지 않았다. 개별 review_note에 전사·구두점·전고·용어 검토 사유를 남겼다. 유형명과 본문이 통념상 충돌한다고 원문을 임의 정정하지 않았다.

## 실제 검증

- Python 자동 검사 13건 통과: 기존 업로드·원본 비저장·검수 저장 충돌·교차 출처 차단·엑셀 왕복 유지, 새 사전/내보내기, 원문 증거 일치, 미확정 측정값 처리, 비유한 수치 차단, 사람별 가중치, 시험 분할 혼입 거부, 퇴화 경계 처리.
- 격리된 검수 저장 테스트는 임시 디렉터리에서 실행했다. 실제 자료의 사용자 독립 검수 수는 0이다.
- 브라우저 검증 결과는 동봉한 browser_checks.json을 확인한다. 최종 결과가 없는 경우 브라우저 검증 완료로 해석하지 않는다.
- 기존 CNN 가중치는 재학습하지 않았다. 이번 변경은 학습 대상이었던 v1 외형 레이블을 바꾸지 않는다.

## 외부 입력이 필요한 남은 작업

1. K-FACE 자료 제공 승인 및 실제 데이터 수신. 신청자·책임자 실제 서명이나 기관 승인, 상업화 허가를 대신 생성할 수 없다.
2. 전통 유형에 대한 두 명 이상의 독립 사진 검수와 원문 전문가 검토. 현재 AI 초벌을 사람이 검수한 것으로 기록하지 않는다.
3. 기준점 검증과 거리·기기·표정별 반복 촬영. 실제 촬영 없는 오차 폭과 허용 각도는 확정하지 않는다.
4. 위 근거로 크다/보통/작다의 경계·보류 구간을 동결하고 새 레이블로 CNN을 학습·평가한다. 현재 모델이 귀미 등 전통 유형을 분류한다고 주장하지 않는다.

## 실행 및 파일

작업대: 기존 `start-workbench.ps1`로 시작. 이미 켜져 있다면 서버를 재시작해야 새 API가 반영된다.
독립 사전: `outputs/knowledge-v2/관상문헌_측정사전.html`을 브라우저에서 연다.

재생성 명령:

```text
python scripts/build_interpretation_catalog.py
python scripts/build_type_requirements.py
python scripts/build_measurement_pilot.py
python scripts/build_knowledge_page.py
python -m unittest discover -s tests -v
```

Windows에서는 프로젝트 `.venv/Scripts/python.exe`에 필요한 패키지가 설치되어 있다. WSL 기본 Python은 사전 생성·통계 일부만 실행 가능하며 영상 분석 패키지가 별도로 필요하다.
