FaceTeller 관상 자료 통합 반영 — 2026-10-16

반영한 자료
- 제공받은 gwansang.json과 gwansang.xlsx의 생김새 58개, 출처 136개를 대조했다.
- 원문·번역·해설·순위·출처 URL과 생김새별 설명이 일치함을 확인했다.
- JSON 원본과 출처 전체는 DB에 보존하고 서비스 결과는 생김새별 하나로 묶었다.

결과 표시
- ‘해당하는 관상 유형’과 ‘문헌에 남은 기록’을 ‘관상 풀이’ 하나로 합쳤다.
- 일자미와 일자 눈썹은 한 카드다.
- 제공된 좋은 종합풀이를 표시하고, 공통 성별 출처 중 순위가 가장 앞선 원문을 대표로 둔다.
- 같은 생김새의 출처가 여러 개여도 카드나 점수를 늘리지 않는다.
- 모든 필요한 형태 조건이 확정된 유형만 점수 순으로 최대 5개 선정한다.
- 사진·측정선 옵션, 원문과 출처 펼치기, 모바일 화면, A4 인쇄를 유지했다.

연결 범위
- 현재 모델의 판정과 연결한 유형: 18개. 미연결 유형: 40개.
- 미연결 사유는 data/release/gwansang/bindings.json에 각 유형별로 기록했다.
- 필요한 측정값이 없거나 검증이 부족한 항목을 다른 특징으로 대신 판정하지 않는다.
- 성별을 입력받지 않으므로 남성·여성 한정 출처와 유형은 자동 연결하지 않는다.
- ‘눈보다 긴 눈썹’은 CNN 판정 외에 실제 눈썹털 길이/눈 폭 1.15 이상을 확인한다.
- 자료의 나머지 숫자는 앱용 제안값이다. 이 숫자로 기존 CNN·VGGT 경계를 바꾸거나 다시 학습하지 않았다.
- 눈꼬리 과대 연결, 코뿌리만으로 산근의 살집 판정, 코밑점 기준 턱 돌출을 아랫입술 기준으로 바꾸는 연결은 사용하지 않는다.

검사
- 백엔드 관련 단위 검사 134개 통과. 무GPU import 검사는 독립 프로세스로 실행했다.
- Claude가 화면 통합을 맡았고 프런트엔드 단위 검사 36개, 화면 검사 13개와 빌드를 통과했다.
- 기존 400명 분류 결과를 새 문헌 선정 방식으로 재검사: 중복 유형·잘못된 원문 연결·점수 계산 오류 없음.
  이 검사는 새 모델 추론이 아니다. 저장되지 않은 눈썹 실측값은 만들지 않고 해당 연결을 제외했다.
- 실제 원본 사진 3장 입력을 8명 대상으로 다시 실행: 대표 출처, 조건 충족, 기하평균, 순서, 측정선 검사 통과.
- 별도 실제 브라우저 실행 1회: 데스크톱·모바일, 단일 풀이 목록, PDF 1쪽, 사진 옵션과 측정선 검사 통과.
- 브라우저 오류와 외부 사진 전송 없음. 테스트에 사용한 얼굴 사진은 결과 파일이나 Git에 저장하지 않았다.
- 분류 정확도에 대한 새로운 사람 검증이나 모델 재학습을 실시한 것은 아니다.
